# Contributing to Calyx Command Bridge

Contributions are welcome.

## Development principles

- Preserve operator control over command execution.
- Never introduce automatic host-command execution.
- Maintain sandbox isolation and fail-closed authentication.
- Keep credentials out of source control.
- Document changes affecting security or deployment.
- Prefer portable, reproducible implementations.

## Pull requests

1. Describe the problem and proposed change.
2. Explain any security implications.
3. Include tests where practical.
4. Verify Python compilation.
5. Never include real credentials or private network details.

## Reporting issues

Use GitHub Issues for ordinary bugs and feature requests.
Report security vulnerabilities privately.
