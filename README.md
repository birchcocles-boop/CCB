# Calyx Command Bridge

**Version 0.5.0 — Development Preview**

Calyx Command Bridge is an experimental open-source project
for running Bash scripts inside an isolated Podman container
through a mobile web interface.

Features:
- Mobile command console
- Tailscale HTTPS access
- 30-day paired-device authentication
- Device revocation
- Rootless Podman sandbox
- Restricted CPU, memory, network, and filesystem access

See INSTRUCTIONS.txt for installation guidance.

Security: Experimental software. Container isolation does not
guarantee protection against host compromise.

See SECURITY.md and CONTRIBUTING.md.
